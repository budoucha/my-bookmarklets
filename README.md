# my-bookmarklets
ブラウザのブックマークレットを管理・共有するためのカタログサイトです。
GitHub Pages を利用して、追加したブックマークレットを自動的にWebページに反映・配信します。

- **GitHub Pages**: [https://budoucha.github.io/my-bookmarklets/](https://budoucha.github.io/my-bookmarklets/)

---

## 🚀 使い方

1. **[My Bookmarklets](https://budoucha.github.io/my-bookmarklets/)** にアクセスします。
2. 左側のサイドバーから、利用したいブックマークレットを選択します。
3. 詳細パネルで説明を確認し、右上の **Copy** ボタン、またはサイドバーのコピーアイコンをクリックして実行用コードをコピーします。整形済みコードが必要な場合は、**Formatted Code** 見出し横の **Copy** ボタンからコピーできます。
4. お使いのブラウザ（Chrome, Edge, Safari, Firefoxなど）で新しいブックマークを作成し、URL欄にコピーしたコードを貼り付けて保存します。
5. 対象のWebページを開いた状態で、作成したブックマークをクリックして実行します。

### 特定のブックマークレットへの直リンク

一覧ページを開いた時点で特定のブックマークレットを選択した状態にするには、`b` クエリでブックマークレットのディレクトリ名を指定します。

- `https://budoucha.github.io/my-bookmarklets/?b=akizuki-copy`

## 🛠️ 新しいブックマークレットの追加・反映仕様

本リポジトリでは、特定のディレクトリ構造とファイル配置のルールに従うことで、**ビルドや手動のリスト更新をすることなく、GitHub Pagesに自動でブックマークレットが追加・反映される**仕組み（仕様）になっています。

### ディレクトリ構造の仕様

リポジトリのルート直下に、ブックマークレットごとのディレクトリを作成します。

```text
my-bookmarklets/
├── index.html
├── app.js
├── styles.css
├── README.md                # このファイル
│
├── [bookmarklet-folder-name]/  # 追加するブックマークレットのディレクトリ
│   ├── README.md               # ブックマークレットの説明と表示名（必須）
│   ├── bookmarklet.js          # 整形された開発用ソースコード（必須）
│   └── bookmarklet.min.js      # 実行用の最小化・1行化コード（必須）
│
└── akizuki-copy/            # 既存のブックマークレットの例
    ├── README.md
    ├── bookmarklet.js
    └── bookmarklet.min.js
```

### 必要なファイルとその仕様

各ブックマークレットのディレクトリ配下には、以下の3つのファイルを必ず配置してください。

#### 1. `README.md` (説明と表示名)
* **役割**: ブックマークレットの詳細説明、使い方、注意点などを記述します。
* **表示名の仕様**: ファイルの **最初の1行目の `h1` 見出し（`# タイトル`）** が、GitHub Pagesのサイドバー一覧における表示名（`displayName`）として自動的に抽出・使用されます。
* **コンテンツ**: 表示名以外のMarkdown部分は、詳細パネルの説明エリアにそのままHTMLとしてレンダリングされます。

#### 2. `bookmarklet.min.js` (実行用コード)
* **役割**: 実際にブックマークとして登録する、スペースや改行を省いて1行に最小化したJavaScriptコードです。
* **仕様**: **必ず `javascript:` から始まる必要**があります。
  * 例: `javascript:(async()=>{ /* 処理 */ })();`
* **機能**: コピーボタンをクリックした際にクリップボードにコピーされるのは、このファイルの内容です。

#### 3. `bookmarklet.js` (開発用・整形コード)
* **役割**: 開発やコードレビューを容易にするための、人間が読みやすい形式にインデント・改行されたソースコードです。
* **機能**: 詳細パネルの下部にある「Formatted Code」エリアに読み込まれ、表示されます。

### 除外されるディレクトリ
以下のディレクトリは自動反映の対象外（無視）となります：
* ドット `.` で始まるディレクトリ（例: `.git`, `.github` など）
* `node_modules`

## 🔄 Pagesに反映される仕組み（内部仕様）

GitHub Pagesのフロントエンド（`app.js`）は、以下の手順で動的にデータを取得し画面を構築しています。

1. **ディレクトリのリスト取得**:
   GitHub REST API (`/repos/budoucha/my-bookmarklets/contents`) を呼び出し、リポジトリのルート直下にあるディレクトリ（ブックマークレット候補）の一覧を取得します。
2. **メタデータの取得**:
   見つかった各ディレクトリ内の `README.md` を raw.githubusercontent.com から並列で取得し、`#` 見出しからブックマークレットの表示名を取得してリストに表示します。
3. **詳細情報の取得と描画**:
   ユーザーがブックマークレットを選択すると、そのディレクトリ内の `bookmarklet.min.js`、`bookmarklet.js`、および `README.md` の中身を個別にフェッチし、画面に描画します。

この仕様により、**`main` ブランチに上記ルールに沿った新しいフォルダをプッシュ（またはマージ）するだけで、即座にPagesに反映されます**。

## 💻 ローカル開発・検証方法

本リポジトリは純粋な静的ファイル（HTML, CSS, JavaScript）で構成されているため、特別なビルド手順は不要です。

1. リポジトリをクローンします：
   ```bash
   git clone https://github.com/budoucha/my-bookmarklets.git
   cd my-bookmarklets
   ```
2. 簡易HTTPサーバーを起動してブラウザで確認します（例: PythonやNode.jsを使用）：
   * **Python 3**:
     ```bash
     python3 -m http.server 8000
     ```
   * **Node.js (npx)**:
     ```bash
     npx serve .
     ```
3. ブラウザで `http://localhost:8000` (または表示されたポート) にアクセスします。

> **注意**: ローカル環境からでもGitHubのパブリックなAPIを呼び出すため、インターネット接続が必要です。また、短時間で頻繁にリロードすると、GitHub APIのレートリミット（認証なしの場合はIPあたり1時間に60回）に達することがあります。
