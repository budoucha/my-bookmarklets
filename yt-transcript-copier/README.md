# YouTube 字幕コピー ブックマークレット

YouTubeの動画ページで表示できる「文字起こし」から、字幕テキストをクリップボードにコピーするためのブックマークレット。

## 概要

YouTubeの動画ページでブックマークレットを実行すると、画面右上に小さな操作パネルを表示する。

操作パネルでは、以下の2種類のコピー形式を選べる。

1. 本文のみ
2. 時間 + 本文

初期状態では `本文のみ` が選択される。

## ブックマークレット

詳細画面の **Copy** ボタン、または `bookmarklet.min.js` の内容をブックマークのURL欄に登録する。

`bookmarklet.min.js` は `javascript:` から始まる1行の実行用コード。`bookmarklet.js` はレビュー・改修用の整形済みコード。

## 登録手順

### Chrome / Edge の場合

1. ブックマークバーを表示する

   * Windows / Linux: `Ctrl + Shift + B`
   * macOS: `Command + Shift + B`

2. 適当なページをブックマークする

3. 作成したブックマークを右クリックして、`編集` を選ぶ

4. 名前を変更する

   例：

   ```text
   YouTube字幕コピー
   ```

5. URL欄の中身を削除し、`bookmarklet.min.js` の内容を貼り付ける

6. 保存する

## 使い方

1. YouTubeの動画ページを開く

2. 文字起こしが利用できる動画で、ブックマークレットを実行する

3. 画面右上に表示される `字幕コピー` パネルでコピー形式を選ぶ

4. `選択した形式でコピー` をクリックする

5. 成功すると、選択した形式の字幕がクリップボードにコピーされる

文字起こし欄がまだ表示されていない場合は、ブックマークレット側で「文字起こしを表示」ボタンのクリックを試みる。取得できない場合は、YouTube側で手動で文字起こし欄を表示してから、パネル内の `字幕を表示・再取得` をクリックする。

## 出力形式

### 本文のみ

```text
こんにちは
今日はこの動画について説明します
まず最初に……
```

### 時間 + 本文

```tsv
0:00	こんにちは
0:03	今日はこの動画について説明します
0:07	まず最初に……
```

`時間 + 本文` の区切り文字はタブ。

## 取得ロジック

現在のYouTube UIで使われている以下の要素を優先して取得する。

```text
transcript-segment-view-model
.ytwTranscriptSegmentViewModelTimestamp
```

字幕本文は、各 `transcript-segment-view-model` 内の `span` 要素から取得する。

また、古いUI向けに以下の要素もフォールバックとして参照する。

```text
ytd-transcript-segment-renderer
.segment-timestamp
.segment-text
```

## 注意事項

このブックマークレットはYouTubeのページ内DOM構造に依存している。

そのため、YouTube側のUIやHTML構造が変更された場合、字幕を取得できなくなる可能性がある。

## 既知の制限

* 字幕または文字起こしが存在しない動画では利用できない
* YouTubeの全画面表示中は、操作パネルが見えない場合がある
* YouTube側が字幕一覧を仮想スクロールしている場合、DOM上に存在する行だけを取得する可能性がある
* ブラウザやページの状態によっては、クリップボードへの自動コピーが失敗する場合がある

## 拡張案

今後、必要に応じて以下のような機能を追加できる。

* 文字起こし欄を自動スクロールして全行を収集する
* SRT / VTT 形式でコピーする
* 句読点や改行を整形する
* 日本語・英語など字幕トラックを選択する
* Webページ上に固定ボタンとして常駐させる
